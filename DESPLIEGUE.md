## 🚀 Opción 1: Publicar en GitHub Pages (Recomendada)

Ya hemos dejado configurado el proyecto para que puedas publicarlo en tu GitHub con **1 solo comando**.

### Pasos:

1. **Sube el código a tu repositorio de GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Premios Losver Gacorta 2026 - Fase 1"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/premios-verga-corta.git
   git push -u origin main
   ```

2. **Despliega la web con un comando**:
   ```bash
   npm run deploy
   ```
   *Esto compilará la app y creará la rama `gh-pages` automáticamente.*

3. **Activa GitHub Pages en el repositorio**:
   * En tu repositorio de GitHub, ve a **Settings** > **Pages**.
   * En **Source**, selecciona `Deploy from a branch` y elige la rama **`gh-pages`** / `/ (root)`.
   * En 1 minuto tendrás tu enlace listo: `https://TU_USUARIO.github.io/premios-verga-corta/`

## ☁️ Opcional: Conectar con Supabase para Sincronización en la Nube

Por defecto, los envíos se respaldan localmente en la memoria del dispositivo y son 100% seguros y privados. Si deseas que los amigos envíen desde distintos móviles y todo se centralice en tiempo real en la nube:

1. Crea un proyecto en [Supabase](https://supabase.com).
2. Crea la tabla `nominations` ejecutando este SQL en el **SQL Editor**:
   ```sql
   create table nominations (
     id bigint generated by default as identity primary key,
     user_name text not null,
     category_title text not null,
     category_description text,
     submitted_at timestamp with time zone default timezone('utc'::text, now()) not null
   );
   ```
3. Agrega tus claves en el archivo `.env.local`:
   ```env
   VITE_SUPABASE_URL=https://tu-proyecto.supabase.co
   VITE_SUPABASE_ANON_KEY=tu-anon-key
   VITE_ADMIN_PIN=VERGA2026
   ```
